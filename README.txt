STREET WEAR — VERSION 100% FRONT-END (HTML/CSS/JavaScript)

Lancement :
1. Décompressez le dossier streetwear_html.
2. Ouvrez index.html dans Chrome, Edge ou Firefox.
3. Pour l'administration, cliquez sur Admin ou ouvrez admin.html.
4. Code admin initial : 1234 (modifiable dans app.js).

Important : cette version ne nécessite ni PHP, ni MySQL, ni XAMPP.
Les catégories, produits et commandes sont enregistrés dans le stockage local (localStorage) du navigateur et sur cet appareil uniquement. Ce n'est pas une base de données en ligne multi-utilisateur. Pour une vraie boutique publique avec commandes reçues sur plusieurs appareils, il faudra un backend/API.
Images de démonstration conservées dans le dossier uploads.
